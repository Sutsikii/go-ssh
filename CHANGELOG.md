# Changelog

## 0.1.0

- Inventaire des serveurs : ajout un par un, en lot, import de ~/.ssh/config (avec ProxyJump) et d'un export gossh
- Groupes, tags, couleurs, favoris, récents ; mot de passe pour toute une sélection (chiffré avec DPAPI)
- Clés d'hôtes vérifiées, approuvables une par une ou toutes d'un coup
- Terminaux en onglets, mosaïque, saisie diffusée à tous les terminaux, recherche, copier/coller
- Statistiques en direct sans agent : CPU, mémoire, charge, réseau, disques ; vue d'ensemble, cartes, liste triable, graphiques
- Commandes groupées en parallèle, relancer les échecs, copier sa clé publique sur tous les serveurs
- Palette Ctrl K, thèmes clair et sombre
- Mises à jour automatiques depuis les releases GitHub
